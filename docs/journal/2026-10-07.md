## What I learned (in my own words)
- PX4 = independent modules talking only through uORB topics. The rates expose the cascaded control loop (outer loops slow, inner loops fast).
- PX4 doesn't know it's simulated: `gz_bridge` feeds it clock + sensor data and takes motor speeds back.
- PX4's local frame is NED, so +z is down and altitude = −z. ROS uses ENU, so there will be sign flips at that boundary.
- QGC connected with zero config because the SITL GCS link defaults to `127.0.0.1:14550`.
